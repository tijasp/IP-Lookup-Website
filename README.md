# IP Lookup Website

A personal portfolio deigned to look and feel like an Ubuntu terminal.
You can explore it by interacting with a command line interface.

🚀 **Live demo:** https://tijasp.github.io/IP-Lookup-Website/

## ✨ Features

-   **Easy to use**
-   **Display:** ISP, Country, Region/state, City, Latitude & Longitude of location, Timezone


## ⚙️ Used technologies

-   **HTML5** - Page structure.
-   **CSS3** - Styling and terminal layout.
-   **JavaScript** - API Fetching and DOM modifications.
-   **API** - ip-api.com to get IPs infos.


## 🚀 Getting started
#### 1. Clone the repository
`git clone https://github.com/tijasp/IP-Lookup-Website.git`

#### 2. Open the project
Navigate to the project directory:
`cd IP-Lookup-Website`

#### 3. Run the project
Open index.html in you browser or deploy a local development server such as the Live Server extension in Visual Studio Code.
